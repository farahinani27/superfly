# Obsolete QR artwork — do not send these to a printer

These files are kept only so nobody wonders what happened to them.

`pilot-qr-SUS-AS-UNI-330-SC-BK.svg` / `.png` encode:

```
https://warranty.superflymotos.com.my/r/SUS-AS-UNI-330-SC-BK
```

**That host does not exist.** It comes from the original design spec, which
planned a separate `warranty.` subdomain. That architecture was abandoned —
the form was built inside Unicart instead. Anything printed from these files
would scan to nothing.

`sus-as-uni-330-sc-bk.png` is an earlier pilot from the same dead design.

The live artwork is one directory up, generated by `make-qr.py`, and encodes
`https://superflymotos.com.my/warranty?v=<code>`.

## Retired 2026-09-28: the per-colour codes

`warranty-ASSCBK.*` and `warranty-ASBKGD.*` encode:

```
https://superflymotos.com.my/warranty?v=ASSCBK
https://superflymotos.com.my/warranty?v=ASBKGD
```

Those URLs still resolve, but the model changed: there is now **one QR per
product type**, because a single card is sealed into boxes of every colourway
and cannot know which colour it is sitting in. The customer picks the colour
from a dropdown on the form instead.

Nothing was ever printed from these. The live artwork is
`warranty-AIRSUS330.*`, one directory up.
